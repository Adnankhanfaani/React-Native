# 📱 Expense Tracker App

A modern and user-friendly **Expense Tracker Mobile Application** developed using **React Native**, **Expo**, and **Firebase** as part of my **Mobile Application Development** course.

The application helps users efficiently manage their daily expenses with a clean interface and secure cloud-based data storage.

---

## ✨ Features

- 🔐 User Authentication
- ➕ Add New Expenses
- ✏️ Edit Existing Expenses
- 🗑️ Delete Expenses
- 📋 View Expense History
- ☁️ Firebase Firestore Integration
- 📱 Responsive and User-Friendly Interface
- ⚡ Cross-Platform Mobile Application

---

## 🛠️ Technologies Used

- React Native
- Expo
- JavaScript (ES6+)
- Firebase Authentication
- Firebase Firestore
- React Navigation
- Async Storage
